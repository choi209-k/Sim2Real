# Sim2Real 자작 사족보행 로봇

시뮬레이션에서 강화학습으로 학습한 보행 정책을, STS3215 서보로 직접 만든 소형 사족보행 로봇에서 실행하는 포트폴리오 프로젝트입니다.

네이버 커넥트 로보틱스 컵(Isaac Sim 기반 보행 과제)에서 시뮬레이션 안에서만 걷게 했던 경험을, 실물 로봇으로 이어 가는 것이 목표입니다.

- 현재 상태: **계획 확정, 1단계 시작 전** (코드 없음)
- 자세한 설계: [docs/design.md](docs/design.md)
- 다음에 이어서 할 일: [docs/next-steps.md](docs/next-steps.md)

## 확정한 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 로봇 | Go2 구조를 참고한 축소형 자작 로봇 (다리당 3관절, 총 12관절) | Go2 실물은 비싸고 저수준 제어가 모델에 따라 막혀 있음 |
| 모터 | Feetech STS3215 C001 (7.4V) 12개 + 예비 | 저렴하고 각도·속도·부하를 읽을 수 있음 |
| 목표 동작 | 느린 보행 (전후 ±0.15m/s 정도) | 고감속 서보라 빠른 동작은 불가능. 포트폴리오용이라 느려도 됨 |
| 정책 | Go2 정책을 축소하지 않고 자작 로봇 모델로 새로 학습 | 무게·길이·모터 특성이 달라 정책을 옮길 수 없음 |
| 학습 도구 | MuJoCo Playground | Colab GPU로 학습 가능, 같은 서보를 쓴 Open Duck Mini 사례가 있음 |
| 정책 실행 | 노트북에서 ONNX로 50Hz 실행 | 작은 신경망이라 낡은 노트북 CPU로 충분 |
| 통신 | 노트북 → USB → FE-URT-2 → 서보 버스 (유선) | 블루투스는 지연이 들쭉날쭉해 보행 제어에 부적합 |
| IMU 연결 | ESP32 DevKit V4가 IMU를 읽어 USB 시리얼로 노트북에 전달 | 나중에 Wi-Fi로 전환 가능 |
| 서버 | 학습에만 사용, 실시간 제어 루프에는 넣지 않음 | 매 스텝 통신하면 지연이 쌓임 |

## 단계별 계획

각 단계가 그 자체로 포트폴리오 결과물이 되도록 나눴습니다. 3단계까지만 끝나도 완성된 결과물입니다.

| 단계 | 내용 | 결과물 | 예상 기간 | 상태 |
|---|---|---|---|---|
| 1 | 서보 1개 특성 측정, MuJoCo 모델과 비교 | 실물 대 시뮬레이션 응답 그래프 | 2~3주 | 시작 전 |
| 2 | 다리 1개(서보 3개) 제작, 시뮬레이션과 실물 궤적 비교 | 비교 영상과 그래프 | 2~3주 | 시작 전 |
| 3 | 전체 조립, 서기, 사인파 걸음 | 정책 없이 걷는 영상 | 4~6주 | 시작 전 |
| 4 | MuJoCo Playground에서 보행 정책 학습 | 시뮬레이션 보행 영상 | 3~4주 | 시작 전 |
| 5 | 실물에 정책 적용 | 실물 보행 영상 | 4주 이상, 불확실 | 시작 전 |

기간은 주당 10시간 기준 추정입니다.

## 부품

| 부품 | 수량 | 보유 |
|---|---|---|
| ESP32 DevKit V4 | 1 | 있음 |
| Feetech FE-URT-2 (USB 버스 서보 어댑터) | 1 | 있음 |
| 3D 프린터 | 1 | 있음 |
| STS3215 C001 (7.4V) | 12 + 예비 2 + 측정용 1 | 구매 필요 |
| IMU 모듈 (BNO085 권장) | 1 | 미정 |
| 7.5V 10A 이상 어댑터 (개발용 전원) | 1 | 구매 필요 |
| 18AWG 전선, XT60 커넥터, 스위치, 15A 퓨즈 | 한 세트 | 구매 필요 |
| M2, M2.5, M3 볼트·너트, 열 인서트 | 한 세트 | 구매 필요 |
| PETG 또는 PLA+ 필라멘트, TPU 소량 | 각 1롤 | 구매 필요 |

무선으로 전환할 때 추가: 2S 리튬폴리머 배터리(2200mAh, 30C 이상), 충전기, 저전압 경보기, 라즈베리파이와 5V 강압 모듈.

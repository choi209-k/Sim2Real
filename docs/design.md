# 설계 메모

아래 수치 중 서보 사양은 기억에 의존한 값입니다. 구매처 데이터시트로 확인한 뒤 고쳐 쓰세요.

## 시스템 구조

```
[서버 / Colab]  학습 → policy.onnx
                         │ (파일 복사, 실시간 연결 아님)
                         ▼
[노트북]  50Hz 루프: 센서 읽기 → 정책 실행 → 목표 각도 전송
   │ USB                          │ USB 시리얼
   ▼                              ▼
[FE-URT-2] ── 서보 버스 ──   [ESP32 DevKit V4] ── I2C ── [IMU]
   STS3215 × 12
```

## 서보: STS3215 C001과 Go2 모터의 차이

| | Go2 모터 | STS3215 C001 |
|---|---|---|
| 방식 | 저감속 토크 제어, 손으로 돌아감 | 고감속(1:345) 위치 제어 서보 |
| 토크 | 약 20Nm 이상 | 정지 토크 약 1.9Nm (7.4V) |
| 속도 | 매우 빠름 | 느림 (대략 초당 270도) |
| 특성 | 충격 흡수 가능 | 유격 있음, 충격에 기어가 약함 |

연속으로 쓸 수 있는 토크는 정지 토크의 1/3 정도(약 0.5Nm)로 보고 설계합니다.

## 기구 설계 기준

- 전체 무게 1.5kg 이하 (서보 12개만 약 660g)
- 허벅지와 종아리 길이 각각 8~10cm 이내
- 다리당 3관절: 어깨 좌우, 어깨 앞뒤, 무릎. 서보를 관절에 직접 장착
- 서보 뒷면 보조 축까지 써서 링크가 서보를 양쪽에서 잡도록 설계
- 발바닥은 TPU로 둥글게 출력
- 몸통은 PETG, IMU는 몸통 중앙에 단단히 고정
- 토크가 부족하면 무릎만 12V 30kg·cm 버전으로 교체하는 방안 검토

## 전원과 배선

- 개발 중에는 7.5V 10A 이상 어댑터로 유선 공급
- 서보 12개를 한 줄로 잇지 않고, 몸통 분배 지점에서 다리별 3개씩 네 갈래로 나눔
- 동시 부하 시 순간 10A 이상 흐를 수 있으므로 18AWG 전선과 15A 퓨즈 사용
- 서보는 모두 같은 ID로 출고되므로 조립 전에 하나씩 연결해 1~12번으로 바꾸고 라벨 부착

## 정책 설계

| 항목 | 내용 |
|---|---|
| 입력 (45개) | 몸통 각속도 3, 중력 방향 3, 속도 명령 3, 관절 각도 12, 관절 속도 12, 직전 행동 12 |
| 출력 (12개) | 관절 목표 각도 = 기본 서 있는 자세 + 0.25 × 출력값 |
| 신경망 | 3층 MLP (512-256-128), PPO |
| 제어 주기 | 50Hz |
| 속도 명령 범위 | 전후 ±0.15m/s 정도 |

- 입력은 실물에서 측정되는 값만 사용. 몸통 이동 속도는 정책 입력에서 빼고 학습 중 critic에만 제공
- 보상: 명령 속도 추종, 몸통 수평 유지, 행동 급변 벌점, 토크 벌점, 발 미끄러짐 벌점
- 서보가 약하므로 행동 급변과 토크 벌점을 Go2 설정보다 크게

## 시뮬레이션과 실물을 맞추는 핵심

1. **서보 모델**: MuJoCo 위치 제어 액추에이터에 토크 한계, 속도 한계, 마찰, 기어 관성을 넣음. 값은 1단계 측정으로 결정
2. **서보 내부 가속 제한 끄기**: STS3215의 자체 가속·속도 프로파일을 최대값으로 풀어 시뮬레이션에 없는 지연을 제거
3. **무작위화**: 마찰, 무게, 서보 게인, 명령 지연(0~30ms), IMU 노이즈, 관절 영점 오차, 외부에서 미는 힘
4. **영점 보정**: 조립 후 각 서보의 0도가 모델과 일치하는지 확인. 몇 도만 어긋나도 정책이 넘어짐

## 1단계: 서보 특성 측정 방법

1. 서보에 길이를 아는 막대를 달고, 끝에 무게를 아는 추를 단다
2. 목표 각도를 갑자기 바꾸는 명령과 사인파 명령을 주고, 실제 각도를 초당 100번 이상 기록한다
3. 추 무게를 서너 가지로 바꿔 반복한다
4. MuJoCo에 같은 막대와 추를 만들고 같은 명령을 준다
5. 시뮬레이션의 게인, 마찰, 토크 한계, 기어 관성을 조정해 두 그래프가 겹치게 만든다

여기서 얻은 값을 4단계 학습의 서보 모델로 그대로 사용합니다.

## 안전

- 실물 테스트는 로봇을 매달거나 거치대에 올린 상태에서 시작
- 명령이 0.2초 이상 끊기면 서보 토크를 풀거나 정지 자세로 가도록 구현
- 리튬폴리머 배터리는 저전압 경보기와 함께 사용
